# C++ Student Record Manager

A command-line program for storing and managing student records using C++.

## Status
Starter project. Build, test and update this README with your own results before marking it complete.

## Concepts
Structures/classes, vectors, functions, loops, input validation and file handling.

## Planned features
- Add a student with roll number, name and marks.
- List all saved students.
- Search by roll number.
- Update or delete a record.
- Save and load records from a file.

## Build
```bash
g++ main.cpp -std=c++17 -Wall -Wextra -o student_manager
./student_manager
```
